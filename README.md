# 🌿 Paradise Nursery – Online Plant Shopping Cart

## 📌 Project Overview

**Paradise Nursery** is a dynamic online plant shop application that allows users to browse a collection of plants, view plant details, and manage their shopping cart.

The project was developed as a final project to apply web development concepts learned through previous practice exercises. It focuses on creating an interactive and user-friendly e-commerce experience for purchasing plants online.

## ✨ Features

* 🌱 Browse a collection of plants
* 🖼️ View plant images and details
* 📝 Display plant names, descriptions, and prices
* 🛒 Add plants to the shopping cart
* ➕ Increase or decrease item quantities
* 🗑️ Remove items from the cart
* 🔢 Dynamically update cart quantities
* 💰 Automatically calculate the total cost
* 🧭 Navigation bar for easy website navigation
* 💻 Interactive and user-friendly interface

## 🛠️ Technologies Used

* **HTML** – Structure of the web pages
* **CSS** – Styling and layout
* **JavaScript** – Dynamic functionality and shopping cart operations

## 🛍️ Application Workflow

1. Users visit the **Paradise Nursery** website.
2. Plants are displayed with their images, names, descriptions, and prices.
3. Users can add their preferred plants to the shopping cart.
4. The cart dynamically updates the quantity of selected plants.
5. Users can increase or decrease quantities.
6. Users can remove plants from the cart.
7. The total cost is automatically recalculated based on the selected items and quantities.

## 🎯 Project Objective

The main objective of this project is to demonstrate the implementation of a functional shopping cart application using web development technologies. It combines HTML, CSS, and JavaScript to create an interactive e-commerce-style website.
